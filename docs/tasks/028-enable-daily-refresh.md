# 028 定期取得の有効化

状態: done / 依存: 025（親: 013）

## 目的
雀魂の一覧は種類ごとに最新50件なので、取りこぼさないよう、登録した雀魂アカウントの候補を1日1回程度、自動で更新するかを決め、有効にする。

## 読むべき資料
- `docs/architecture.md`「非同期の処理」「雀魂に負荷をかけない運用」
- `docs/deploy.md`（Scheduler `jantama-ranking-daily`）

## 作業範囲
- 有効にするかの判断（2026-11-20 ユーザーの判断で「後で決める」としたもの）
- 有効にするなら、`infra/schedule.tf` の状態を ENABLED にし、時刻を決める。失敗の通知の送り先を確かめる

## 完了条件
- 有効にするかが決まり、`docs/decisions.md` にある。有効にしたなら、定期取得で候補が更新されたことを確かめた

  - 有効にするときの前提: 失敗・警告をメールで受け取れるようにする。`refreshAll` のアカウントごとのエラーと、`runJob` のジョブ全体の失敗にも `[通知]` を付ける。時刻は 7:00 JST のままでよい
