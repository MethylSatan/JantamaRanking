# 003 GAS スクリプトとシートのサンプルをリポジトリに取り込む

状態: todo / 依存: なし

## 目的
リポジトリ外にある GAS スクリプトとスプレッドシートのサンプルを、リポジトリで管理できるようにする。

## 読むべき資料
- `docs/architecture.md`（構成要素）

## 作業範囲
- ユーザーに、GAS スクリプトの現物と、スプレッドシートのサンプルの場所を教えてもらう
- GAS は `gas/` などに置く（`clasp` で管理するかは、ユーザーと相談）
- シートの構成（試合結果シートの列、集計の式）を `docs/architecture.md` に書く
- 個人情報（メンバー名、シートID）が含まれていないか確認し、含まれるものはコミットしない

## 完了条件
- GAS スクリプトがリポジトリに入っている（または、入れない理由が決定ログにある）
- シートの構成が文書になっている
