# 003 GAS スクリプトとシートのサンプルをリポジトリに取り込む

状態: done / 依存: なし

## 目的
リポジトリ外にある GAS スクリプトとスプレッドシートのサンプルを、リポジトリで管理できるようにする。
**前提（2026-11-19）**: GAS とスプレッドシートはやめ、Web サービスで集計する（タスク 008）。このタスクの主な目的は、集計のルール（順位点、ウマ・オカ、ランキングの並べ方など）を移植できる形で文書にすること（タスク 012 の前提）。

## 読むべき資料
- `docs/architecture.md`（構成要素）

## 作業範囲
- ユーザーに、GAS スクリプトの現物と、スプレッドシートのサンプルの場所を教えてもらう
- GAS は `gas/` などに置く（`clasp` で管理するかは、ユーザーと相談）
- シートの構成（試合結果シートの列、集計の式）を `docs/architecture.md` に書く
- 個人情報（メンバー名、シートID）が含まれていないか確認し、含まれるものはコミットしない

## 完了条件
- GAS スクリプトがリポジトリに入っている（または、入れない理由が決定ログにある）
- シートの構成が文書になっている

## メモ
### 2026-11-19（完了）
- 入手: スプレッドシートはユーザーが URL を共有（**変更禁止**）。xlsx で書き出して読んだ。GAS（四麻用・三麻用）は会話に貼ってもらった。牌譜 json のサンプルは `local/probe/` に置いてもらった（前期・後期の2形式）。具体は `docs/local/003-sheet-notes.md`
- 成果: `gas/import4p.gs`・`gas/import3p.gs`（ID は伏せた）。`docs/architecture.md` に「旧集計（スプレッドシート）」の節（シートの役割、列、牌譜 json の2形式、GAS の処理、pt と順位、ランキングの作り方、移植の注意）
- 分かったこと
  - pt は GAS ではなく雀魂の計算した値（`total_point / 1000`）。ウマは四麻 5-15、三麻 0-15、オカなし（部屋の設定）
  - 順位は GAS が pt の大きい順につけていた。シートの全対局で一致した
  - 集計はプレイヤー名（ニックネーム）でまとめ、累計 pt の大きい順に並べる
  - 年別シートで12月31日の対局が入らない、四麻の「今月参加済み」が3日からになっている、という式の不具合とみられる点がある（タスク 012 へ申し送り）
- clasp は使わない（決定ログ）
