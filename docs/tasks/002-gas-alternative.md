# 002 GAS 依存をやめる方式の検討

状態: done / 依存: 001

## 目的
**前提（2026-11-16）**: 目指す形はセルフサービスの Web サービス（`docs/product.md`）。取り込みと集計を Web サービスで行う案を、比べる候補に入れる。サービスの構成はタスク 008 と合わせて考える。
Drive へのアップロード → GAS 実行、という手作業を伴う取り込みをやめる方式を決める。スプレッドシートは当面続ける前提で考える。

## 読むべき資料
- `docs/product.md`（未決事項）
- `docs/architecture.md`（データの流れ）
- タスク003の成果（GAS スクリプトの現物があれば）

## 作業範囲
- 現状の GAS が何をしているか整理する（入力 json の項目、投入先シートの列）
- 置き換え案を比べる。例:
  - ローカルの Node から Google Sheets API で直接投入する
  - 牌譜 json を集計して CSV にし、スプレッドシートに貼る／インポートする
  - スプレッドシートもやめ、ローカルで集計して静的ページに出す
- 認証、運用の手間を比べ、推奨案を決める。非エンジニアが運用できること（コマンド操作や Node の環境構築を要求しない）を重視する
- 決定を `docs/decisions.md` に追記し、実装タスクを起票する

## 完了条件

- 実装タスクが起票されている
