## 新しいタスクの作り方
- ファイル名は `NNN-短い名前.md`（連番）。この表にも行を足す
- 形式は他のタスクファイルと揃える: 目的 / 読むべき資料 / 作業範囲 / 完了条件 / メモ
- 「読むべき資料」には、そのタスクに必要な文書だけを挙げる
