# 026 管理の画面

状態: todo / 依存: 024、025（親: 013）

## 目的
Admin（当面）が画面だけで、ランキングを作り、雀魂アカウントを指定し、候補から取り込む・対象外にする操作をできるようにする。非エンジニアが迷わない画面にする。

## 読むべき資料
- `docs/product.md`（利用者と操作、非機能要件）
- `docs/architecture.md`「API」「非同期の処理」「権限（タスク 022）」
- `docs/deploy.md`「API と OAC」
- `web/public/admin.html`（仮の実装。ログインの流れ）
- `docs/tasks/013-web-ui.md` のメモ（タスク 020 からの申し送り、基盤にあるもの）

## 作業範囲
- Vite + TypeScript + Preact を入れる（`docs/decisions.md` 2026-11-20 タスク 019）。`.github/workflows/deploy.yml` の sync 元をビルド結果に変える（`rankings/` を消さないことは保つ）
- ログイン（Cognito の Hosted UI、認可コード＋PKCE。コールバックは `admin.html`、本番と `http://localhost:5173/`）。仮の `admin.html` を置き換える
- ランキングの一覧・作成・名前の変更・削除、雀魂アカウントの指定・外す
- 候補の一覧（日時・ルール・参加者）→ 取り込む / 対象外にする。ジョブの進み具合の表示。一覧の上限の警告の表示
- 取り込み済み・対象外の一覧と、対象外にする・戻す。操作ログ。作り直し。公開 URL の表示と取り直し
- `/api/me` の許可の表で、できない操作のボタンを出さない
- 画面の文では Admin を「管理人」と書く

## 完了条件
- Admin が画面だけで、主催者の新しい対局を取り込み、ランキングに反映できる

## メモ
- 2026-11-25 に 013 から分けた（`docs/decisions.md` 2026-11-25 タスク 013 の分割）
- Host の付け外しの画面は作らない（タスク 023）
