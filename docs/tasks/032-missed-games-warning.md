# 032 取りこぼしの警告を、主催者がリーグ以外の友人戦も打つ前提に直す

状態: todo / 依存: 025

## 目的
候補の更新の警告（`src/collector/collect.ts` の `listCandidates`）は、一覧が40件以上なら「上限が近い」、50件ちょうどで一番古い対局が未処理（取り込み済みでも対象外でもない）なら「取りこぼしたおそれ」と出す。これは、一覧に出る対局をすべて取り込むか対象外にする前提になっている。主催者はリーグ以外の友人戦も打つので、未処理の対局が残るのはふつうで、警告がいつも出て意味がない（ユーザーの指摘、2026-11-27 タスク 030）。本当に取りこぼした（一覧から外れて、もう取れない対局がある）ときだけ知らせるようにする。

## 読むべき資料
- `docs/architecture.md`「牌譜回収（タスク 006）」「取り込みの手順」
- `src/collector/collect.ts`（`listCandidates`・`LIST_WARN_AT`）、`src/api/jobs.ts`（`refreshRanking`・`refreshAll`）

## 作業範囲
- 取りこぼしの判断を、処理済みかどうかではなく、前回の更新とのつながりで行う案: 雀魂アカウントごとに、前回の一覧で見えた対局（または一番新しい対局の時刻）を覚えておき、今回の一覧の一番古い対局がそれより新しければ、間が抜けた（取りこぼした）とする。候補の対局は全件を保存している（`MAJSOUL#<内部 ID>` / `GAME#`）ので、それと比べられるかもしれない。四麻・三麻は別に見る
- 初めての更新（前回が無い）では、一覧が上限に達していれば「これより古い対局は取れない」と知らせるだけにする
- 「上限が近い」の警告をやめるか、残すなら何のために出すかを決める
- 画面の文（`web/src/lib/format.ts` の `jobSummary`）と、定期取得の `[通知]` を合わせて直す

## 完了条件
- リーグ以外の友人戦が未処理で残っていても、取りこぼしが無ければ警告が出ない（自動テストで確かめる）
- 前回の更新から一覧の上限を超えて対局が増えたときは、警告が出る（自動テストで確かめる）
