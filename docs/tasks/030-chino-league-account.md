# 030 ちのリーグに主催者の雀魂アカウントを指定し、新方式との間の欠けを確かめる

状態: done / 依存: 015、031

## 目的
旧方式の対局を入れた本番のランキング「ちのリーグ」（タスク 015）に、主催者の雀魂アカウントを指定し、新方式の候補から取り込めるようにする。あわせて、旧方式の最後の対局と、新方式の一覧の一番古い対局の間に、どちらでも取れない期間が無いかを確かめる。

## 読むべき資料
- `docs/tasks/015-legacy-data-migration.md` のメモ
- `docs/local/015-migration-notes.md`（ランキング ID）、`docs/local/006-collector-notes.md`（新方式の一覧の期間）

## 作業範囲
- 主催者の雀魂アカウントを、管理の画面の「設定」の「対局の参加者から選ぶ」で指定する（タスク 031。表示用 ID は聞かない。配信者は表示用 ID を気軽に公開しない）
- 候補の更新を1回行い、主催者の一覧が取れることを確かめる
- 一覧の一番古い対局（四麻・三麻）と、旧方式の最後（2024-12-23）の間に欠けが無いかを見る。タスク 006 の時点では、四麻の一覧は 2025-05-01 から、三麻は 2024-12-10 からだった。四麻の 2024-12-24〜2025-04-30 に対局があったかはユーザーに確かめる（タスク 018 のメモでは、ユーザーの確認で欠けは無いとしている）
- 旧方式と重なる対局（三麻の 2024-12-10〜12-23）は、ランキングで状態を持つので候補に出ないことを確かめる
- 候補のうち、ちのリーグに入れる対局を取り込む（どれを入れるかはユーザーが決める）

## 完了条件
- ちのリーグに主催者の雀魂アカウントが指定され、欠けの有無が記録されている

## メモ
- 2026-11-27: 管理の画面の「参加者から選ぶ」と同じ API（`PUT .../accounts/{内部 ID}`）で、ちのリーグに主催者を指定した。名前は対局から付いた。候補の更新（ログイン1回）で、四麻・三麻とも50件が返り、内部 ID は手元の主催者と同じだった
- 欠け: 三麻の一覧は旧方式の最後より前（2024-11）から始まり、重なる42局は取り込み済みとして候補に出なかった。欠けは無い。四麻の一覧は 2025-05-01 からで、2024-12-24〜2025-04-30 はこの方式では見えない。この期間に対局が無いことはユーザーが確認済み（タスク 018 のメモ）
- 取り込み: ちのリーグは休止中で、新方式の一覧（2024-11〜2026-11）にリーグの対局は無い（ユーザー）。何も取り込まず、候補58局（四麻50・三麻8）はそのまま残した（対象外にもしていない）
- 一覧の上限による押し出し: 11/19（タスク 006）に見えていた四麻1局（2025-05-01）が、その後の対局で一覧から外れていた。リーグの対局ではないので取り込まない。中身は手元（`local/collector/out/`）にある
- 候補の更新の警告（「取りこぼしたおそれ」「上限が近い」）が、リーグ以外の友人戦のせいで出続ける。意味が無いので、タスク 032 に起票した（ユーザーの指摘）
