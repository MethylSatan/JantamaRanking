# 004 利用者向けのヘルプページを書く

状態: done / 依存: 013（Web サービスの公開）

## 目的
利用者（閲覧者・主催者）が、画面操作だけでランキングを見たり更新したりできるよう、使い方を書く。
当初は README の「導入方法」として書く予定だったが、Web サービスになり利用者は何も導入せず、リポジトリも見ないので、サイト内のヘルプページに書く（`docs/decisions.md` 2026-11-27 タスク 004）。

## 読むべき資料
- `docs/architecture.md`（管理の画面・閲覧の画面・取り込みの手順・権限）
- 画面のソース（`web/src/`）。ボタンや見出しの表記を合わせる

## 作業範囲
- `web/public/help.html`: ランキングの見方、主催者の申請、ランキングの更新（雀魂アカウントの指定 → 候補の更新 → 取り込み・対象外 → 公開 URL）、気をつけること、困ったとき
- スクリーンショット（`web/public/help/`）。実データが写らないようにする
- 管理・閲覧の画面のフッターとトップ（`index.html`）からリンクする
- README は、リポジトリの紹介とヘルプページへのリンクにする（旧方式の説明と図を外す）

## 完了条件
- エンジニアではない初見の人が、ヘルプページだけを見て、ランキングを見る・主催者の申請をする・候補を更新して取り込むまで進める

## メモ
- 2026-11-27: 作成。画像は、本番の画面を Playwright で開き、`page.route` で `/api/**` と `/rankings/*.json` を架空のデータ（ニックネームは「ぽん太」など）に差し替え、`sessionStorage` に架空のトークンを入れて撮った。ログインも本番の変更も無い。撮影のスクリプトはリポジトリに置いていない（画面が変わって撮り直すときは、同じ方法で作り直す）
- 主催者の視点（`via: host`）で撮った。管理人だけの操作（ランキングの作成・主催者の付け外し・利用者の承認）はヘルプに書いていない（利用者向けではない）
- `architecture.png`（旧方式の図）は README から外した。更新はタスク 034
