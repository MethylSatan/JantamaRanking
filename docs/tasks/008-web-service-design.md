# 008 セルフサービスの Web サービスの構成検討

状態: done / 依存: 007

## 目的
牌譜の取り込みと集計対象の選定を、利用者がセルフサービスで行える Web サービスにする（`docs/product.md` 目指す形）。その構成を決める。

## 読むべき資料
- `docs/product.md`（目指す形、未決事項）
- `docs/decisions.md`（2026-11-16 の回収方式・ログイン方式）
- `docs/tasks/007-l2-login-investigation.md`（L2 の結論）
- `docs/tasks/002-gas-alternative.md`（集計先の検討。合わせて考える）

## 作業範囲
- 利用者と役割を決める（主催者・運営・閲覧者のうち、誰が何を操作するか）。利用者の認証の要否も決める
- 主な画面の流れを決める: 主催者の指定 → 候補の対局の一覧 → 取り込む対局を選ぶ → 集計・ランキングを見る
- サーバー側の部品（L2 での雀魂接続、タスク 006 の回収処理）、データの置き場所、集計の出力先（スプレッドシートを続けるか。002 と合わせる）を決める
- 置き場所と費用を比べる（小規模・非商用。無料枠で収まるか）
- 雀魂の API を公開サービスから使うことの規約面での判断と、サーバーに負荷をかけない運用（要求の間隔・回数の上限）を整理する。規約面の判断は `docs/local/` に書く
- 決定を `docs/decisions.md` に書き、実装タスクを起票する

## 完了条件
- 構成と理由が `docs/decisions.md` と `docs/architecture.md` に書かれている
- 実装タスクが起票されている
