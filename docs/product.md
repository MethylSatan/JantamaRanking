# プロダクト要件

## 目的
雀魂の友人戦の牌譜を集計し、メンバーごとの成績をランキング形式で見られるようにする。
元は、Vtuber の東風乃ちのさんのメンバー限定友人戦向けに作った。

## 対象
- 利用者: 友人戦を開催する主催者（牌譜の取得と集計を行う人）
- 閲覧者: 友人戦の参加者（ランキングを見る人）
- 主催者・閲覧者ともエンジニアではない想定。コマンド操作や環境構築を前提にしない
- 需要は東風乃ちのさんのコミュニティ次第。汎用ツールとしての保証はしない

## 機能要件（現状の半自動フロー）
1. 雀魂の画面で、友人戦の牌譜URL一覧を取得する（Tampermonkey）
2. 牌譜データを json でダウンロードする（Tampermonkey、または `PaifuImporter`）
3. 牌譜を Google Drive にアップロードし、GAS でスプレッドシートの試合結果シートに投入する
4. スプレッドシートで集計し、ランキングにする

## 非機能要件
- 雀魂のサーバーに過度な負荷をかけない
- アクセストークンなどの認証情報を公開しない
- 主催者が手作業で回せる手間に収まる
- 手順は、非エンジニアがブラウザ操作中心でこなせること

## スコープ外（現時点）
- 完全自動化（雀魂へのログインを含む）
- 友人戦以外（段位戦・大会戦）の集計
