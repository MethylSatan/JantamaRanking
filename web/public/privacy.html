プライバシーポリシー

このサイト（友人戦ランキング）は、雀魂の友人戦の成績をランキングにまとめる、個人が運営する非公式のサイトです。雀魂の運営会社とは関係ありません。

ランキングを見る人

ランキングを見るのにログインは要りません。見る人の情報は集めません。

ログインする人（管理人・主催者）

管理人と主催者は、Discord のアカウントでログインします。

  • 受け取る情報: Discord からは、ユーザー ID だけを受け取ります。メールアドレス、名前、所属するサーバーなどは受け取りません。このほか、主催者の申請で本人が書いた名前とひとことを保存します。
  • 使い道: ログインと、申請を承認するかの判断、操作してよい人かどうかの確認にだけ使います。申請の内容と Discord のユーザー ID は管理人だけが見ます。
  • 置き場所: Amazon Web Services（東京リージョン）に、暗号化して保存します。
  • 第三者への提供: しません（サイトの運用に使う Amazon Web Services を除きます）。
  • 削除: 不要になったとき、または本人から頼まれたときに消します。下の連絡先にご連絡ください。

ログインした人の情報は、管理人が承認するか、却下するまで保存します。却下したとき、本人が申請を取り下げたとき、承認した人が利用をやめたときは、その人の情報を消します（操作の記録には、個人を直接示さない内部の番号だけが残ります）。利用者が50人に達しているときは、新しいログインを断り、情報は残しません。

雀魂の対局の記録

ランキングを作るため、主催者の友人戦の記録（対局の日時、参加者の雀魂のニックネームと ID、点数と順位）を雀魂から取得して保存し、ランキングとして公開します。ランキングに載りたくない場合や、記録の削除を希望する場合は、下の連絡先にご連絡ください。
