プライバシーポリシー

このサイト（友人戦ランキング）は、雀魂の友人戦の成績をランキングにまとめる、個人が運営する非公式のサイトです。雀魂の運営会社とは関係ありません。

ランキングを見る人

ランキングを見るのにログインは要りません。見る人の情報は集めません。

ログインする人（管理者・主催者）

管理者と主催者は、Discord のアカウントでログインします。

  • 受け取る情報: Discord のユーザー ID だけです。メールアドレス、名前、所属するサーバーなどは受け取りません。
  • 使い道: ログインと、操作してよい人かどうかの確認にだけ使います。
  • 置き場所: Amazon Web Services（東京リージョン）に、暗号化して保存します。
  • 第三者への提供: しません（サイトの運用に使う Amazon Web Services を除きます）。
  • 削除: 不要になったとき、または本人から頼まれたときに消します。下の連絡先にご連絡ください。

許可されていない Discord のアカウントでログインしようとした場合は、その場で断り、情報は残しません。

雀魂の対局の記録

ランキングを作るため、主催者の友人戦の記録（対局の日時、参加者の雀魂のニックネームと ID、点数と順位）を雀魂から取得して保存し、ランキングとして公開します。ランキングに載りたくない場合や、記録の削除を希望する場合は、下の連絡先にご連絡ください。
